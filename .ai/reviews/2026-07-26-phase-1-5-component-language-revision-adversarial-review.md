# Phase 1.5 Component-Language Revision Adversarial Review

**Status:** Risks bounded; implementation may proceed
**Date:** 2026-07-26

| Risk | Failure mode | Required mitigation |
| --- | --- | --- |
| Cosmetic-only refactor hides actions | A shorter interface makes a required Phase 1 command unreachable | Keep every accepted command bound to a visible contextual control and rerun the full journey |
| Reduced copy hides corrective evidence | The interface looks cleaner but no longer explains a blocked action | Preserve affected item, short cause, and next action when a constraint exists; move routine detail out of the permanent rails |
| Rounded brushes are inconsistent | Some native or Blueprint controls retain default rectangular Slate resources | Source all production and gallery brushes from one theme helper; audit screenshots for default brushes |
| DPI scaling breaks geometry | Large radii, fixed tiles, or field rows overlap at 150–200% | Use compact drawers at 175–200%, bounded field widths, wrapping, and five-scale captures |
| Visual hierarchy depends on color | Cyan/amber/green alone communicate state | Pair color with labels, borders, shape, and status words |
| Decorative chrome consumes the world | Larger headers and trays recreate the text-wall proof | Keep the orthographic world as the largest continuous region and collapse inactive detail |
| Default font limits concept fidelity | Unreal's bundled type lacks the concept's illustrated personality | Use deliberate bold/regular hierarchy, shadow, casing, and spacing now; defer a licensed project font until provenance review |
| Native/Blueprint drift | The Blueprint root and native fallback render differently | Keep one native composition source for this bounded revision; exercise the cooked Blueprint subclass that inherits it |
| Button state regression | Hover, focus, pressed, and disabled variants become indistinguishable | Give every variant distinct fill, outline, and label contrast; inspect the component gallery |
| Polish claim outpaces evidence | Automated screenshot existence is mistaken for visual similarity | Require human side-by-side inspection and owner approval after the recapture |
