# Code Organization Standard

- Keep code files at or below 2000 lines.
- Prefer logically focused files over broad multi-purpose modules.
- If an existing code file is over 2000 lines, mention it in the final summary for the task and recommend a focused follow-up split.
- Do not refactor large files opportunistically unless the user asked for that work or the change requires it.
