# Styles And Themes

Use this directory to track project aesthetics, UI rules, visual design decisions, and reusable UI templates.

Before creating UI components:
1. Review `.ai/styles/ui-templates.md`.
2. Reuse an applicable template when one exists.
3. If no applicable template exists, create a template first, then implement the component from it.
4. Keep visible text content separate from implementation instructions.
