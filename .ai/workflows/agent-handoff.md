# Agent Handoff

Use this workflow when work moves between agents, sessions, branches, or worktrees.

Every handoff must record:
- owner and next owner
- branch or worktree
- current objective
- changed files
- verification already run
- blockers and open risks
- next concrete action

Store durable handoffs under `.ai/handoffs/`.
