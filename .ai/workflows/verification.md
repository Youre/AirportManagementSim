# Verification Workflow

Use this workflow after implementation or review work.

1. Run the smallest command set that proves the behavioral claim.
2. Record command, result, and notes with `ai-init record-verification`.
3. If verification is skipped, record why and what risk remains.
4. Mention failed, skipped, or incomplete verification in the final task summary.
