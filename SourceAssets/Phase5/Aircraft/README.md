# Phase 5 fictional freighters

These SVG masters are project-authored, top-down, orthographic aircraft for
Airport Management Sim. They use the Riverbend navy, cyan, and amber palette,
contain no external source geometry, and are retained outside cooked content.

- `Riverlark_F28.svg`: compact feeder freighter.
- `Hearthwing_F62.svg`: larger regional freighter.

Runtime raster size is 512 × 512 with a centered pivot. Unreal Paper2D imports
use 32 pixels per meter and reviewed heading variants are created by rotating
the neutral top-down master in presentation code.
