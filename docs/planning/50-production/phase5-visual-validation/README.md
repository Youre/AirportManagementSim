## Highest-impact comparison notes

### P5-01

1. VA-04 is timetable-led, while cargo needs a spatial warehouse flow; the
   retained contract rail and cyan selection language preserve the planning
   relationship.
2. VA-03 uses individual passenger routes; Phase 5 intentionally aggregates
   shipments but retains direction, compatibility, exception, and location.
3. The concept references carry more decorative density. Runtime prioritizes
   readable capacity, current work, and one bounded action.

### P5-02

1. VA-05 centers one aircraft and its services; the cargo frame matches that
   hierarchy with freight-specific equipment and build-up stages.
2. Cargo quantity and storage replace passenger/baggage details without
   changing the dependency-first visual grammar.
3. Fictional freighter silhouettes are simpler than concept aircraft art so
   headings remain legible at operational zoom.

### P5-03

1. VA-07 suggests specialization branches; Phase 5 deliberately removes
   exclusivity and shows simultaneous evidence.
2. The four capability bands are explicit; Major stays future-locked.
3. Each card uses a label plus evidence, not color alone, and the selected
   inspector explains requirements and business/spatial effects.

### P5-04

1. VA-01's airport overview remains visible rather than becoming an
   event-only dashboard.
2. VA-06's localized closure language is reused for temporary runway windows,
   emergency readiness, and cleanup.
3. Display flying is authored/abstract; arrivals, stands, spectators,
   concessions, staffing, and closures use normal systems.

## Reusable rules promoted from the frames

- Keep normal-operation side rails compact enough for a continuous world
  region of at least 60%; use drawers at 175-200%.
- Use one clear title, one short cause/remedy, and one primary action per card.
- Pair every state color with text, icon, border, pattern, or progress.
- Show cargo flow in both UI and world; do not represent authoritative
  movement as an isolated progress bar.
- Event surfaces must state what remains open and visibly preserve ordinary
  airport activity.
- Major remains visible but locked; no Phase 5 screen implies wide-body
  support.
