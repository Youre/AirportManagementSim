## Highest-impact differences

1. VA-03 is a close terminal cutaway with authored furniture, passengers,
   queues, and a selected party; P6-02 is a macro-capacity design frame and
   therefore remains less materially detailed.
2. The concept follows one party's needs and confidence; P6-02 promotes
   throughput, gate availability, baggage reservation, and access modes
   because those are the Phase 6 state changes.
3. VA-03 uses many small construction tools and route legends; P6-02 keeps the
   established Major-operations navigation and two contextual actions.

## Intentional differences

- The terminal is shown as four capacity regions rather than a literal
  building floor plan. Existing Phase 3/4.5 detailed terminal props remain
  the runtime vocabulary; this board validates the Phase 6 capacity layer.

## Bounded correction completed

The original aggregate scale frame was not accepted as a substitute. A
dedicated terminal frame now separates check-in/security, gates, baggage, and
public access; adds continuous route overlays; exposes exact capacity; and
records the current shared-resource reservation. Acceptance observation: all
Phase 6 terminal content categories and their dependencies are visible in one
scan, while the remaining prop-density difference stays explicit for owner
review.
