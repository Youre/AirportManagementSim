# VA-01 Visual Comparison — Airport Overview

**Equivalent state:** Mature Riverbend airport during normal mixed operations  
**Board:** [actual versus concept](va01-airport-overview.png)

## Review

- The world remains the dominant continuous region and carries runway,
  taxiway, apron, terminal, GA, operations, fuel, parking, transit, access,
  landscaping, aircraft, vehicle, staff, passenger, and bag evidence.
- Navy rounded rails, cyan selection, amber attention, green confirmation,
  coral risk, and off-white type retain the approved Riverbend language.
- The persistent top status and time controls, contextual inspector, tool rail,
  selection ring, and visible activity make this the same player state as the
  concept.
- Statuses pair labels and symbols with color. The gameplay cursor remains
  visible and interactive.

## Highest-impact differences

1. The concept has denser vegetation, decorative props, lighting, shadows, and
   atmospheric depth.
2. The implementation uses more diagrammatic facility sprites and less
   architectural micro-detail.
3. The concept's left tool rail is more pictorial; the implementation favors
   compact icon-plus-label controls for reliable recognition.

## Intentional differences

- The implementation remains strict top-down 2D and query-derived; decorative
  perspective and non-authoritative crowd placement were not copied.
- The selected entity inspector exposes actual readiness, capacity, service,
  and schedule state rather than concept placeholder values.

## Bounded correction completed

Later-phase auto-navigation was removed. The overview is now a stable explicit
destination, with selection and contextual navigation remaining available
without another presenter replacing it.
