# VA-02 Visual Comparison — Construction

**Equivalent state:** Starter airfield construction in progress  
**Board:** [actual versus concept](va02-construction.png)

## Review

- Construction cost, team activity, project status, runway/taxi/stand/hut
  footprint, active objective, and time controls are visible in one state.
- World placement remains primary and the construction card is anchored near
  the affected site.
- The cyan/green build treatment, amber cost, navy cards, rounded frames, and
  concise labels align with the shared component language.

## Highest-impact differences

1. The concept depicts a mature build-mode palette and detailed extension
   geometry; this fixture deliberately shows the first starter-airfield build.
2. The implementation footprint is schematic and has substantially less
   construction equipment, terrain variation, marking detail, and scenery.
3. The concept exposes more pre-commit cost and conflict meters, while the
   current state emphasizes authoritative in-progress status.

## Intentional differences

- The screenshot represents an active starter construction, not a runway
  extension proposal, because that is the deterministic Phase 1 acceptance
  boundary.
- Only feasible, implemented starter controls are shown; illustrative build
  categories that are not available in this state are omitted.

## Bounded correction completed

The contextual first-use card was moved away from the creation controls and
the affected construction card was kept inside the world region, preserving
the action hierarchy and usable viewport.
