# Phase 7 Help and Accessibility Scale Review

**Surface:** Production Release Guide  
**Resolution:** 1920 x 1080  
**Captures:** `scales/100-release-guide.png` through
`scales/200-release-guide.png`

| Scale | Layout | Result |
| ---: | --- | --- |
| 100% | Full five-tab rail and complete content card | Pass |
| 125% | Full rail; larger readable text; bounded content | Pass |
| 150% | Full rail; no clipped action or setting | Pass |
| 175% | Compact navigation; scrollable content; no text shrink | Pass |
| 200% | Compact navigation; scrollable content; no text shrink | Pass |

The guide uses the Riverbend navy rounded shell, cyan selected tab, amber
attention, green confirmation, and off-white type. `START`, `CONTROLS`,
`AIRPORT`, `OPERATIONS`, and `ACCESSIBILITY` remain reachable at every scale.
Captions-on, reduced-motion, camera-shake-off, scale choices, and reset remain
visible or reachable through bounded scrolling.

Status is never color-only. Focus, selection, and setting state retain text and
shape treatment. The guide does not capture the mouse for gameplay and closing
it restores the combined game/UI input policy with a visible cursor.

The automated scale matrix checks the rendered dimensions and confirms compact
mode at 175-200%. Final subjective readability confirmation remains in the
owner's consolidated post-Phase-7 test.
