## Highest-impact mismatches

1. VA-01 still has richer terminal architecture, curbside dressing, shadows, and material depth than the modular runtime campus.
2. The concept distributes more vehicles, aircraft, people, landscaping, and service activity across the entire airport rather than concentrating identity inside the terminal.
3. VA-01 includes a large bottom aircraft inspector; the current equivalent state retains the compact radio/navigation footer.

## Intentional differences

- The terminal is permanently roofless on the one authoritative airport canvas so its editable interior remains continuously visible.
- Runtime object positions, quantities, and activity come from deterministic simulation state rather than incidental concept values.
