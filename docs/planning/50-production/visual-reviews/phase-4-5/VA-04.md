## Highest-impact mismatches

1. The implementation is a genuine time-based seven-day grid, but normal-scale
   flight cards still carry three compressed text rows instead of the
   concept's more icon-led two-level hierarchy.
2. The selected recurring offer combines project-owned operator identity,
   aircraft silhouette, route, frequency, capacity, reward, selection, and
   acceptance state. The shared Cessna silhouette remains a temporary
   role-agnostic substitute for final fictional regional aircraft art.
3. The authoritative rain-restricted flight has an amber striped, time-bounded
   `D3 11:30-12:35 / NS 223` overlay and concise `WX` card copy. A confirmed
   affected flight inside the locked horizon now uses the same localized,
   color-independent treatment with explicit `LOCK RISK ///` text.

## Intentional differences

- Phase 4 owns a seven-day authored timetable with exact daily slots, so days
  are the grid columns. The concept's stand columns and denser incidental
  schedule were not copied.
